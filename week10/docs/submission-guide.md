# Week10 제출 가이드

이 폴더는 AWS 없이 제출 가능한 형태로 정리된 산출물입니다.

제출에 포함할 내용
- 프런트엔드 자동 배포 + PR 프리뷰 설명
- Docker 기반 배포 전략 설명
- 클라우드 배포 자동화/헬스체크/모니터링 설명

추천 제출 방식
1. GitHub Pages를 쓰는 경우: `docs/frontend-pr-preview.md`에 따라 설정
2. Vercel/Netlify를 쓰는 경우: Preview URL을 함께 제출
3. Docker 전략은 `docs/docker-strategy.md`를 제출 문서에 포함

실제 배포 URL이 있으면 가장 좋고, 없으면 워크플로 파일과 전략 문서만으로도 과제 요건을 설명할 수 있습니다.
